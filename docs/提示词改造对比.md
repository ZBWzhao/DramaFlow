# 提示词改造对比：从「导演手记」到「机位单」

> 本文所有提示词均为系统里**真实生成的文本原文**，不是示意。
> 旧文本取自项目 `story-钟声-单镜-86b1f078`（改造前生成），新文本取自 `story-钟声-工艺版-a1a46dd6`（改造后生成）。
> 两个项目用的是**同一份剧本**，所以差异只来自提示词工艺，不来自内容。

---

## 一页结论

片子难看，主因不是模型能力，是提示词缺了「工艺层」：我们把**给人看的说明书**喂给了模型，而模型要的是**施工图**。

| | 改造前 | 改造后 |
|---|---|---|
| 角色资产 | 1 张「默认形象」，提示词 = 设定原文 + 标签串 + 规则句硬拼一段 | 2 张独立单图（`正面全身` 锚点图 + `正脸特写`），各自「主体描述 → 机位 → 光线 → 质感 → 负面尾巴」五段式 |
| 场景资产 | 关键词串当描述（「钢蓝色低空、曳光弹、燃烧装甲车残骸、砖石断墙…」） | 一句连续的空间描述 + 明确光源方向 + 「广角，平视，无人物」 |
| 视频提示词 | 导演手记式：`画面/摄影/光线/氛围/声音/资产` 六段，讲「观众该感到什么」 | 机位单式：`@引用` / `景别+机位` / `动作：起点 → 可见末态` / `光线` / `声音` / 两行硬锁 |
| 双人戏站位 | `subject: "@灰蓝士兵"`（只写有谁） | `subject: "画面中央偏左是深棕士兵的下颌与持铲的手，画面中央偏右是灰蓝士兵…两人视线相刺"`（左右 + 视线 + 持械关系） |
| 引用后的外貌 | 用括号把脸型、发型、服装再描一遍 | 只 `@引用`，**明令禁止再描外貌**（参考图与文字是权重冲突） |
| 首帧 | 只有一行摘要 + 一句「定格在动作起点」 | 8 段式：`CHARACTER / ACTION（复用整段正文）/ CAMERA（景别代码）/ LIGHT / TEXT / STYLE` + 参考图锁定 |
| 拆镜粒度 | 36 段 × 4-5 秒（一段一镜），但 `shots[]` 信息不足以支撑构圖 | 17 镜 × 4-6 秒，一镜一段、`shots[]` 写死站位与末态 |

## 1. 角色资产：一张图走天下 → 两张锚点图

### 改造前（`灰蓝士兵` · `默认形象`）

```
男性，25岁上下，短寸头糊满泥灰、发际线沾着血点；脸型偏窄，颧骨高，下巴有短硬胡茬，
眉骨处一道新鲜擦伤；穿灰蓝色粗布野战服，肩章已被撕掉，右袖口开裂，胸前挂帆布弹袋，
头戴灰蓝钢盔、盔沿压到眉梢；中等偏瘦体格，肩背因长时间低姿行动前倾；全身覆，灰蓝钢盔、
短寸头、颧骨高、灰蓝粗布野战服、肩章撕掉、右袖口开裂、帆布弹袋、满身泥浆、肩背前倾
电影级质感
单角度角色设定图：正面全身，平视机位，中性表情，双手自然下垂，全身入画、脚下留少量空间；
棚拍柔光、无强阴影、纯中性灰背景、地面无投影；不出现文字、水印、边框、多格排版、拼图、
第二个人、动态姿势、手持道具
```

三处硬伤：

1. **半句截断**：「全身覆，灰蓝钢盔、短寸头…」——原文应该写到「全身覆盖泥浆」，被标签串直接截断。
2. **标签串冒充描述**：「短寸头、颧骨高、灰蓝粗布野战服…」是给校验器做一致性比对的关键词，不是画面描述，模型读它等于读一串名词。
3. **只有一张图**：特写镜头没有可用的脸，只能拿全身图去裁，一裁脸就崩。

### 改造后（`灰蓝士兵` · 两张单图）

`正面全身`（锚点图）：

```
灰蓝士兵，28 岁上下男性，中等偏瘦体型、肩窄背薄，短寸脏发（泥土结块粘成硬绺），
深灰蓝土布作训服配同色钢盔，袖口磨破、衣料吸满泥浆、膝盖有干泥裂块；右侧脸颊一道旧擦伤，
左肩胛处衣料有圆形焦黄灼痕，钢盔左侧一道凹陷刮痕。正面全身，平视，中性表情，双手自然下垂，
全身入画，脚下留一点空间。棚拍柔光，无阴影，纯中性灰背景，无投影。写实电影质感，皮肤纹理清晰。
不出现文字、水印、边框、多格排版、多余人物。
```

`正脸特写`（派生图，专供特写镜头）：

```
参考正面全身锚点图衍生同一人的正脸特写。28 岁上下男性，短寸脏发、泥土结块粘成硬绺，
右侧脸颊一道旧擦伤，下颌与鼻梁沾干泥，深灰蓝土布作训服领口入画。正脸平视，中性表情，
双眼平视镜头，面颊到头顶入画。棚拍柔光，无阴影，纯中性灰背景。写实电影质感，
皮肤纹理与汗渍泥点清晰。不出现钢盔以外的头部装饰，不出现文字、水印、边框、多格排版、多余人物。
```

改动点与原因：

- **固定顺序**：年龄体型 → 发型 → 服装材质 → 2-3 条可画出的识别特征（旧疤 / 灼痕 / 盔上凹痕）。模型对「先看到什么」敏感，顺序本身就是权重。
- **两种机位拆两张图**：全身图定服装与体态，特写图定脸。**一图一人、不并排**——更早的版本用过「正面/侧面/背面三视图并排」，结果模型把三个视图读成**三个不同的人**，成片出现重复角色（产物见 `workspace/assets/generated/image-1c83aea99b.jpg`）。
- **负面尾巴固定**：「不出现文字、水印、边框、多格排版、多余人物」——不写这句，画面里会冒出水印和第二个头。

## 2. 场景资产：关键词串 → 空间描述

### 改造前（`战场废墟·黄昏`）

```
电影级质感，空间构成：起伏泥地与弹坑，后景横着燃烧的装甲车残骸，中景一堵被打塌的砖石断墙、
堆着碎砖与铁丝网，近景泥洼里散落弹壳与步枪；天空钢蓝色压得很低，曳光弹一道道划过。
光线：黄昏低角度余光与残骸火焰做双光源，火光从画面右后方偏高处打来，在钢盔和断墙，
钢蓝色低空、曳光弹、燃烧装甲车残骸、砖石断墙、弹坑泥地、铁丝网、火光右后高侧、
硬阴影高反差、烟尘散射，场景设定图：无人物广角空镜，画面中没有任何人物；
交代空间结构、光源方向与前后景层次；不出现文字、不出现人物剪影
```

注意第 3 行那句「火光从画面右后方偏高处打来，**在钢盔和断墙**，钢蓝色低空、曳光弹…」——句子在「在钢盔和断墙」处断裂，后面直接接关键词串。**设定、标签、规则三层被硬拼成一段**，模型分不清哪句是画面、哪句是约束。

### 改造后（`废墟窄巷`）

```
两段塌到一半的砖墙夹出的一条窄巷：地面堆满碎砖与碎石瓦砾，巷尽头透出暗红天光，
墙面弹孔密集、局部露出红砖芯体；光线来自巷尾暗红天光与两侧残火的橙红闪烁。
广角，平视，无人物。写实电影质感，胶片颗粒。不出现文字、水印、边框、多格排版、人物。
```

- 一句话读完就是一张照片，**没有一处是给校验器看的**。
- 光源写「来自巷尾暗红天光 + 两侧残火橙红闪烁」——方向和色温都在，视频层才能保持同一场戏的光线连续。
- `广角，平视，无人物` 三个词顶旧版三行规则。

## 3. 道具资产：修掉 `。，` 拼接 bug

### 改造前（`铜口琴`）

```
电影级质感，十孔铜口琴，长约十厘米，外壳黄铜、包浆厚实发暗，边角磨出亮铜色；
上下盖板之间有细小凹痕与一道划痕，吹孔边沿有常年唇触留下的暗色痕迹；两端螺丝氧化发绿，
整体带一层薄灰。，十孔铜口琴、黄铜厚包浆、边角磨亮、盖板细小凹痕、吹孔唇触暗痕、
螺丝氧化发绿、薄灰，道具设定图：白底单品，单件物品居中、完整、无遮挡；等距或正视视角；
不出现人物、不出现文字与 logo、不加环境背景
```

`整体带一层薄灰。，十孔铜口琴…` —— 双标点是拼接痕迹的物证。

### 改造后（`铜口琴`）

```
一支老式十孔黄铜口琴，平放在粗糙水泥面上：黄铜外壳氧化成暗金褐色，边缘鎸刻细纹磨到模糊，
上下音孔板之间卡着干泥，一端有一道弯折窪痕。俯拍平视、微距质感，纯中性灰背景，
棚拍柔光，体现黄铜金属真实反光。写实电影质感。不出现文字、水印、边框、多格排版、人物。
```

道具改动的关键不是措辞，是**给了物品一个姿态**：「平放在粗糙水泥面上」「俯拍平视、微距质感」。道具图是要被视频模型当参考图用的，正视角白底单品在成片里会显得像贴纸；有placement和机位，材质反光才立得住。

## 4. 视频提示词（单人镜）：导演手记 → 机位单

### 改造前（`P01 泥血与耳鸣`，5s）

```
特写｜黑场中溅上镜头的泥土与血点｜本镜无人出镜

画面：起幅是近乎全黑的画面。一声近炸掀起的泥土和血点正面溅上镜头表面，可见层瞬间被糊满——
泥土呈棕色团块、血点是暗红小点，最厚的地方完全遮住画面，只有边缘露出一线极暗的背景光。
摄影：摄影机固定，无运动。焦点贴在镜头玻璃表面，飞溅物是唯一清晰层。
光线：无主光，只有飞溅瞬间的一次爆炸闪光从画面深处掠过，把泥点边缘照亮一瞬又熄灭。
氛围：全黑、噪点粗、高压迫感。

声音：仅环境音：贴耳近炸钝响、高频耳鸣嗡鸣覆盖一切、泥土砸落的细碎声。

资产：@灰蓝士兵、@深棕士兵 本镜完全不出镜，画面中不出现任何人形、手、肢体或脸。
```

这段文字本身写得很好——但它是**导演手记**：讲的是「观众应该感到什么」（高压迫感、只有边缘一线光）。模型不会翻译感受，它只会画被拍的东西。于是它真的画了「泥土糊满一个表面」，产出那张满屏泥浆的抽象特写。

另外两处结构性错误：

- 第一行 `特写｜黑场中溅上镜头的泥土与血点｜本镜无人出镜` 是**片名式三段**，不是机位信息；景别、机位、镜头朝向混在一句话里。
- `氛围：` 这一段没有对应的画面对应物，纯属浪费 token，还会诱导模型去「加氛围」（加雾、加光斑）。

### 改造后（`E1-01 枪机空响`，5s）

```
@灰蓝士兵 @砖石战场废墟
近景，机位与胸口齐平、从废墟侧前方拍，固定机位不运动。

动作：起点：他肩抵枪托、压低身体从画面右侧的塌墙后向前探出，视线穿过墙的缺口看向画面左外；
他扣下扳机的一瞬枪机咔地空响，末态：肩背猛地一僵、头微抬、手指停在扳机护圈上不再动。

光线：主光自画面左侧偏低位的橘红火光打来，脸颊右半侧落进钢蓝阴影，轮廓被身后曳光划出细亮边。

声音：仅环境音：远处爆炸的低频闷响、持续耳鸣、枪机空响的一声金属咔哒。

单镜头连续拍摄，不切镜、不换机位、不出现新角色。
画面中不出现任何文字、字幕、水印，不生成 BGM。
```

- 第一行 `@引用`，第二行就是**机位单**：`景别，机位高度，拍摄方向，是否运动`——四个参数全在。
- `动作：起点 → 末态`：起点决定第 0 秒，末态告诉模型这 5 秒要走到哪。旧版写「两个人在此定格」，模型无法从「定格」推出任何运动，只能让设定图轻微动一下（这正是旧片「战场只是场景图变动态」的成因）。
- 删掉 `氛围：`，压进光线里（「脸颊右半侧落进钢蓝阴影」本身就是氛围）。
- 两行硬锁：不切镜、不换机位、不出现新角色 / 不出文字、不生成 BGM。旧版把「不出现人形」写在 `资产：` 段落末尾，位置太靠后，模型按前面的画面描述已经决定要画人了。

## 5. 视频提示词（双人对手戏）：只写「有谁」 → 写清「谁在哪」

### 改造前（`P20 钢筋抵住喉咙定格`，4s）

分镜数据 `shots[0]`：

```json
{
 "subject": "@灰蓝士兵",
 "action": "反手把 @断裂钢筋 横着抵住 @深棕士兵 的喉咙，两个人同时定格",
 "shot_size": "近景",
 "camera_move": "固定",
 "duration": 4.0
}
```

`subject` 只写了「@灰蓝士兵」——**另一个人在画面哪里、谁在上谁在下、两人视线朝向哪儿，一个字都没有**。正文里补了「在下方/在上方」，但那是相对说法，模型无法换算成画面坐标：

```
画面：@灰蓝士兵（灰蓝钢盔、灰蓝粗布野战服、短寸头、颧骨高、满身泥浆）在下方，反手把
@断裂钢筋（螺纹钢筋、红褐锈迹、拧断毛刺）横着顶住 @深棕士兵（深棕钢盔、深棕军服、
右肩撕口、脸盘宽方、泥浆贴额）的喉咙；@深棕士兵 举着 @工兵铲（铲头、卷刃缺口）停在上方。
```

两个致命细节：

1. **括号里重描外貌**（钢盔、军服、颧骨、脸盘）。参考图和文字是**权重冲突**：描述越细，参考图越失效——所以成片里两个人的脸和设定图对不上。
2. **没有视线目标**。旧片里两人明明是对手，却像战友一样并排蹲着——因为「视线看哪儿」从来没写过，模型按「两人同框」的默认构图把他们对齐摆放。

这一镜碰巧撞对了（首帧见 `workspace/assets/generated/image-8a95f9aee2.jpg`：两人对峙、钢筋抵喉、钟楼在中间）。但**旧工艺的问题是不稳定**，同一场戏的下一镜就崩了——`P21 刀锋离皮肤一寸` 的分镜表是这么写的：

```json
{
 "subject": "@工兵铲 的刀锋与皮肤",
 "action": "刀锋离皮肤一寸悬着，只有胸口起伏，武器在抖",
 "shot_size": "特写",
 "camera_move": "固定",
 "duration": 4.0
}
```

`subject` 不是人，是「一把铲子的刃和一块皮肤」——**画面里没有人物、没有位置、没有谁的皮肤**。首帧模型只能自己发明：一个人把工兵铲怼在自己脸上、对手完全不在画面里（`workspace/assets/generated/image-d1e2166a14.jpg`），视频再忠实地把这个错误构图演了 4 秒。

这就是旧版的真实水位：不是每一镜都烂，而是**好镜头靠运气，坏镜头无法定位原因**。

### 改造后（`E1-11 钢筋抵喉`，5s）

分镜数据 `shots[0]`：

```json
{
 "subject": "画面中央偏左是深棕士兵的下颌与持铲的手，画面中央偏右是灰蓝士兵的下巴与被钢肌抵住的喉咙，两把武器在画面正中交叉；两人视线相刺",
 "action": "铲刃向下砸落的同时钢筋从下方反手顶上去 → 末态：铲刃悬在喉咙上方一寸停住、钢筋顶端抵住对面喉咙，两只武器都在颤，两人胸口起伏",
 "shot_size": "特写",
 "camera_move": "推",
 "duration": 5.0
}
```

正文：

```
@深棕士兵 @灰蓝士兵 @工兵铲 @断裂钢筋
特写，机位与两人喉咙齐高、从交叉武器侧面拍进，缓慢向前推近。

动作：起点：铲刃向下砸落、钢筋从下方反手顶上去；末态：铲刃停在喉咙上方一寸、
钢筋顶端抵住对面喉咙，两把武器都在细颤，两只手各自扶紧，胸口起伏越来越明显。

光线：低位橙红余火自画面下缘往上一尺打亮下颌与武器交叠处，背景压成近乎全黑的碎石色，
武器金属面只留一道冷亮反光。

声音：仅环境音：压抑的呼吸、武器细颤的金属低响。

单镜头连续拍摄，不切镜、不换机位、不出现新角色。
画面中不出现任何文字、字幕、水印，不生成 BGM。
```

- **`subject` 现在是构图说明**：左半画面是什么、右半画面是什么、交叉点在哪、视线朝哪。这四件事写死，模型就没有发挥空间去「把两人并排摆好」。
- **`camera_move: 推`** 是这一镜的唯一运动，人物动作与摄影机运动分开写（旧版把「定格」这种非运动塞进运动字段）。
- **不再重描外貌**：只留 `@深棕士兵`、`@工兵铲`。外观由参考图决定，文字只描述**此刻在干什么**。

> 实事求是：这段 `subject` 里 Agent 把「钢筋」打成了「钢肌」（错别字）。但它落在**正确的槽位**上，属于可修正的噪声，不影响构图理解——旧版的问题恰恰是槽位不存在。

## 6. 首帧提示词：一行摘要 → 8 段式

首帧决定整个镜头的构图，是三层里**最贵也最容易崩**的一层。

### 改造前（`P02 炮火废墟全景` 的首帧提示词）

```
电影级写实剧照，竖屏 9:16 构图。
景别：全景。
画面主体：@战场废墟·黄昏。
定格在动作起点：钢蓝的低空里一道道曳光弹划过，后景燃烧的装甲车残骸爆着火苗，前景断墙与泥地静止。
人物外观严格按角色参考图（服装、泥污、发型一致），场景与光线严格按场景参考图。
构图完整、主体清晰、光影有层次；这是一段镜头的第一帧。
禁止文字、字幕、水印、边框、拼图、多格排版。
```

问题：`ACTION` 只有一行摘要，而且 **`@战场废墟·黄昏` 这种引用写法在首帧提示词里没有展开**——图生图时模型看不到「@」指的是哪张图；同时**这一镜分镜表里的完整正文被丢掉了**。首帧模型于是自己发明构图：这一镜要「大全景空镜」，结果给了中景双人站桩（`tmp/frames5/p02.png`）。

### 改造后（`E1-01` 的首帧提示词）

```
电影级写实剧照，竖屏 9:16 构图。这是下面这一镜的第 0 秒画面，静止定格。
CHARACTER：灰蓝士兵单人，画面偏右，胸口以上入画，身体前半探出塌墙右侧视线，
脸朝画面左侧，眼睛看向画面外对面的塌墙方向。
ACTION：定格在动作起点。画面描述如下：
图片1灰蓝士兵 图片2砖石战场废墟
近景，机位与胸口齐平、从废墟侧前方拍，固定机位不运动。

动作：起点：他肩抵枪托、压低身体从画面右侧的塌墙后向前探出，视线穿过墙的缺口看向画面左外；
他扣下扳机的一瞬枪机咔地空响，末态：肩背猛地一僵、头微抬、手指停在扳机护圈上不再动。

光线：主光自画面左侧偏低位的橘红火光打来，脸颊右半侧落进钢蓝阴影…
[完整正文]
CAMERA：MCU（近景），固定；构图按上面的画面描述，主体完整入画、不裁掉关键动作。
LIGHT：光源方向与色温按场景参考素材，保持同一场戏的光线方向一致。
TEXT：画面中不出现任何文字。
STYLE：写实电影质感，胶片颗粒，色调统一。
身份与外观严格按参考素材（@灰蓝士兵、@砖石战场废墟）：脸型、发型、服装、泥污一致，不重描、不替换。
构图完整、主体清晰、有前中后景层次；不出现水印、边框、多格排版、拼图。
```

四个改动：

1. **正文整段复用**：`ACTION` 段直接嵌入该镜的完整提示词（旧版只喂一行 `action` 摘要）。这是 P21 崩图的直接修复。
2. **`@名字` 翻译成 `图片N名字`**：`图片1灰蓝士兵 图片2砖石战场废墟`，与 API 的 `references` 顺序对齐，图生图时一一对应。
3. **景别代码**：`CAMERA：MCU（近景）`。人读中文、模型也能吃到常见英文缩写，减少景别被理解的歧义。
4. **`CHARACTER` 写死站位与视线**：`画面偏右 / 胸口以上入画 / 脸朝画面左侧 / 眼睛看向画面外`。这四句是「两个对手变战友」的直接解药。

## 7. 拆镜粒度：36 段 4-5 秒 → 17 镜 4-6 秒

| | 改造前 | 改造后 |
|---|---|---|
| 段落数 | 36 | 17 |
| 总时长 | 152 秒 | 82 秒 |
| 每段 | 4-5 秒，1 个镜头 | 4-6 秒，1 个镜头 |
| `shots[]` 字段 | `subject`（谁）、`action`（干什么） | `subject`（谁在哪、看哪）、`action`（起点 → 可见末态） |
| 生成单位 | 段 | 段（一段仍等于一镜，好处是重生成的代价只有 4-6 秒） |

**成本不变**：按秒计价，拆镜不改总时长。真正省钱的是「一镜一句」——一个镜头的失败只损失 4-6 秒的视频钱，而不是 12 秒。

改造前曾经踩过的坑（已废弃）：把 12 秒塞进一段、内部写「0-3 秒特写 / 3-7 秒大全景 / 7-12 秒中景」。视频模型不会切镜，它只能自己猜怎么填满 12 秒——成片里第二幕是从第一幕硬切过去的，就是它猜出来的。

## 旧版四个结构性病根 → 新做法

| 病根 | 旧版表现 | 新做法 |
|---|---|---|
| **散文当指令** | 写「高压迫感」「极度静止」「泥与火的暖色」 | 删掉 `氛围` 段，把感受压进光线与景别（「脸颊右半侧落进钢蓝阴影」） |
| **标签串冒充描述** | 「钢蓝色低空、曳光弹、燃烧装甲车残骸、砖石断墙…」 | 一句连续空间描述；标签串只作为 `consistency_tags` 存数据，不进提示词 |
| **引用后又重描外貌** | 括号里把钢盔、军服、颧骨再写一遍 | 只 `@引用`，明令「不重描、不替换」——外观交给参考图 |
| **站位与视线缺席** | `subject: "@灰蓝士兵"` | `画面中央偏左是…画面中央偏右是…两人视线相刺` |

外加两条**只在首帧层成立**的规则：

- **首帧必须拿到整段正文**，不能只给一行摘要；
- **首帧的参考图按镜筛选**：单人镜只给本人 + 场景，双人镜最多两张角色图，绝不再放三视图拼版。
