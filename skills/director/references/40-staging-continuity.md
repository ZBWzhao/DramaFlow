# 40 · 站位双层 / 运镜衔接 / 跨镜连续性

> 本册解决「多人和跨镜不乱」。生成单元是一镜一段，**每一镜生成时模型看不到任何上一镜画面**，也不依赖上一镜尾帧参考，所以所有空间关系都必须在本镜文字里自包含。

## A5. 站位：世界坐标 + 画面坐标（双层 · 自包含）

### A5.1 每一镜必须写全的 5 块信息

1. **世界坐标 · 轴线与地标**：角色相对门、桌、窗、走廊等真实位置；与机位无关。
2. **画面坐标 · 当前镜头中的左右/前后/遮挡**：随当前机位重新声明。
3. **光源方向 · 世界层 + 画面层**：只在同一连续光照条件下继承。
4. **道具绝对位置与状态**：含本镜移动路径。
5. **本镜结束状态**：下一镜必须把它重写成「绝对初始状态」，不是「延续上一镜」。

一镜也要写这 5 块；这是多人戏不乱的根。

### A5.2 连续场景的状态链

同一地点、同一连续时间内：

`上一镜结束状态 → 下一镜重新写成绝对初始状态 → 本镜动作 → 本镜结束状态`

继承内容：角色实际世界位置与身体朝向；道具位置、持有者、数量、液面、污渍/损耗；伤势、服装、湿度、血迹、烟尘等持续状态；主光方向、色温、环境条件。

### A5.3 人物移动只服从源剧情，不为连续性补动作

禁止 AI 自造无依据的位置变化，也禁止为「解释位置变化」反过来补剧情。

- 原文写「起身走到门口」→ 必须保留起身、行走、到达，不能瞬移。
- 原文下一节拍直接写「角色已经站在门口」→ 把「站在门口」作为既定初始状态，用 HARD CUT / 新镜进入，**不得自行补起身走过去**。
- 原文写两人换位 → 按原文过程执行；原文没写换位 → 不得为构图让二人交换世界位置。
- 画面左右可因合法换机位变化，世界位置不得无源变化。

### A5.4 轴线规则

- 同一连续对话默认维持既有 180° 轴线。
- 用户明确要求反打/越轴，或剧情需要改变轴线时，用中性机位、过轴移动或建立镜头让空间变化可理解。
- 禁止无提示跳轴。**「不越轴」不等于摄影机永远不能换位置。**

### A5.5 换场 / 时间跳跃重新锚定

场景、时间、天气或主光明确变化时：新场景重新建立世界坐标、画面坐标、轴线与光线；不强行继承上一场机位或光线方向；服装、伤势、随身道具是否继承按剧情时间连续性决定。这样能支持 2–3 分钟以上多场景剧情，而不把第一场站位锁死到整集。

## A7. 运镜与镜间衔接

### A7.1 情绪曲线

`低 → 中 → 高 → 释放`（起 / 压力 / 峰值 / 落地）。曲线按原剧情时间顺序记录，不能拿来重排剧情。

### A7.2 情绪位置 → 运镜

峰值分为内心、信息反转、外部动作三类；运镜必须服从用户指定风格，不能因为「峰值」自动推近或自动大特写。

### A7.3 镜间衔接规则（独立生成优先）

**判断范围：只看「镜 N 的末镜」与「镜 N+1 的首镜」。** 镜头属性分三类：拍摄主体（双人/单人/局部/空镜/群体）、景别（全景/中景/近景/特写/大特写）、角度（正面/侧面/背面/过肩/俯视/仰视）。

为避免两个独立生成的镜头在剪辑点看起来像错误续帧，相邻镜默认至少满足一项：
1. 拍摄主体类型不同；2. 景别差 ≥ 2 档；3. 拍摄角度差 ≥ 90°。

三项都不满足时，只允许调整下一镜首镜的**摄影主体/景别/角度/构图**，不得改变该镜对应的源剧情事件、人物位置事实、动作、道具或对白。

- **推荐**：双人中景 → 单人/局部特写；双人中景 → 空镜；单人中景 → 双人中景；局部特写 → 双人中景；空镜 → 双人中景；单人侧面中景 → 单人正面特写。
- **高风险**：同一主体 + 同一景别 + 近似角度直接相邻；同一手部动作在两个独立镜之间硬接。
- 不存在「局部 → 局部一律禁止」这类与三条件冲突的第二套规则；差异足够即可用，但仍要保证连续性易读。

### A7.4 动作连续剪辑

match-on-action **优先只放在同一镜内**：动作进行中 → HARD CUT → 下一镜继续，在独立生成下极易断。跨镜时优先让上一镜完成动作，下一镜从「动作完成后的稳定状态」重新开始。

### A7.5 风格路由表

| 风格 | 运镜 | 表演 | 光线 | 声音 |
|---|---|---|---|---|
| **克制型** | 固定为主 / 峰值也可不动 | 情绪从动作偏差泄露 | 自然光 / 低反差 | 环境音主导 |
| **悬疑型** | 稳定机位为主 / 必要时突然反打 | 信息差核心 / 反应可迟半拍 | 硬阴影 / 侧逆光 | 静默比音乐更有效 |
| **喜剧型** | 固定机位 / 全景定格常有效 | 角色认真演、反差生喜感 | 均匀正常光 | 环境音主导 |

用户已有明确风格时，用户风格为最高优先级。

## A8. 跨镜连续性检查（先判定关联，再校验）

A7.3 是**镜间镜头类型切换的唯一规则来源**；A8 只负责人物、道具、环境和持续状态的连续性。**不能把所有相邻镜都强行串成同一个连续空间，先判断两镜是否真有连续关系。**

### A8.1 先判定相邻镜的连续性关系

对每个 `镜 N 末态 → 镜 N+1 初态`，内部只标以下三类之一：

1. **连续关联**：同一地点、同一连续时间，或源剧情明确是「继续/随后/承接/同一轮对话/同一动作链」，下一镜初态依赖上一镜末态。
2. **局部状态关联**：场景或时间已变化，但源剧情明确要求某些持续状态继续（同一随身道具、服装破损、伤势、湿度、污渍、产品剩余量）。只继承这些持续状态，**不强行继承上一场人物位置、机位或画面左右**。
3. **无连续关联 / 重新锚定**：场景、时间或叙事单元已切换，且下一镜不依赖上一镜位置或道具末态。只检查本镜自身起态、动作、末态；位置、机位、光线按本镜重新建立。

判定依据只来自用户最新明确指令、源剧本和已确认状态。**不得为了「让它连得上」自行制造关联。** 源剧情直接给出下一镜新既定状态却没有过渡过程时，按 A0.1 把它当新初态，用 HARD CUT / 新时间块进入，不补移动或交接前史。

### A8.2 人物位置关系校验（连续关联镜强制）

对每个实际存在连续关联的人物维护状态链：

`镜首绝对位置/姿态 → 源剧情动作 → 镜末绝对位置/姿态 → 下一镜绝对初始位置/姿态`

至少核对：
1. **世界位置**：相对门、桌、窗、走廊、车辆、固定家具等地标是否一致。
2. **相对关系**：谁在谁的哪一侧、前后距离、是否隔着桌/门/柜台，是否无因改变。
3. **身体状态**：站/坐/蹲/躺、身体朝向、面向对象是否连续。
4. **手部占用**：持有道具时哪只手/双手是否仍被占用；源文未锁左右手且镜头无需时不要强行指定，但一旦为执行已明确，就不能在相关镜头无过程换手。
5. **出镜与画外**：裁切或换机位可让人物从画内变画外，不等于人物在世界空间中消失或换位。
6. **移动依据**：位置变化必须能对应源剧情 `E##` 中已有的移动/起身/落座/转身事件，或源剧情直接给出的新初态；没有依据就不能靠镜头切换让人瞬移。

**画面左/右可因合法换机位改变，世界位置不能因此改变。** 反打时先查世界坐标，再重算画面坐标；禁止为保持「永远画面左/右」偷搬人物。

### A8.3 道具状态链校验（镜内 + 连续跨镜强制）

对关键道具、商品和参与动作的小物件维护：

`持有人 / 使用手（若已明确） / 绝对位置 / 可见或被遮挡 / 数量 / 开合状态 / 内容物或液面 / 污渍湿度损耗 / 本镜动作 / 镜末状态`

- 角色无源剧情事件（放下/递出/收起/掉落/离开画面）时，下一时刻道具**不能凭空消失**。
- 裁掉手或道具、被遮挡只算「暂时不可见」，世界状态仍保持，**不可把「没拍到」理解成「消失」**。
- 持物同手下一镜仍清楚可见且无状态变化事件，则该道具应继续在手中。
- 已放下的不能无过程回手；已交给 B 的不能下一镜又同时出现在 A 手中。
- 数量、大小、形态、颜色、开合、液面、损耗、污渍不能无因复制、恢复或改变；进出画面边缘不等于状态变化。

### A8.4 场景与物理环境连续性

仅在「连续关联」或「局部状态关联」时检查：门窗开合、椅子/餐具/家具已发生的移动；地面水迹、污渍、破损、烟雾、食物剩余量等持续状态；主光方向、时间、天气以及实际光源开关；镜子/玻璃/反射面中不应出现与当前人物道具矛盾的额外复制；角色与固定环境不能无依据穿模、穿墙或越过封闭障碍。

### A8.5 跨镜修正边界

发现连续性问题时只允许：修正世界坐标/画面坐标的文字冲突；修正出镜/遮挡描述；修正关键道具的持有、可见性和状态锁；调整镜头承载、景别或切点，使已有动作更易完整呈现；必要时在**已有 `E##` 边界**重新分镜。

**禁止为修连续性新增「把笔放下 / 又拿起来 / 走到另一边 / 重新拿一件」等用户没写的桥接动作。** 冲突来自源剧情自身时，按 A0.1 标「源文本冲突」，不擅自修成另一个故事。

**不要写「同上」「延续上一镜站位」。** 需要继承的下一镜必须把继承结果重新写成绝对初始状态；无连续关系的镜只检查本镜自身。
