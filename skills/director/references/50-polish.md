# 50 · 表演层 / 交付前抛光

> 抛光**只执行一次**：不是第二轮分镜，不重算镜数、不重切节拍、不回滚 `30-output-check.md`。
> 首帧八段式、`@名字` 引用即锁定、文字锁的写法在 `drama_craft`，本册不复述，只写抛光时怎么用。

## A6. 表演层

**A6.1 情绪 = 行为的副产品。** 不写「他很难过」，写他在做什么，情绪从动作的微小偏差里泄露。

**A6.2 目标指向对象。** 只有原剧情能明确看出角色目标时才整理为可执行目标并指向具体人/物/任务；不得为表演完整性推断动机、隐藏目的或关系意图。

**A6.3 状态优先，关键因果动作保留过程。** 拿取/放下/倒液体/开门/换手/坐下/起身/走位不能瞬移。

**A6.4 微表情必须有源剧情依据 + trigger。** 只在源剧情已有对应反应/情绪外显时写，格式 `[已有反应的可见微表情] + [原文触发条件]`；不得因为镜头近就自行加皱眉、抿嘴、脸红、吞咽、苦笑。

**A6.5 mask + crack（仅源剧情支持时）。** mask 只整理用户已给的表面状态，不自行赋予「伪装」；crack 只把已有反应具体化为一个可见破绽，不新增反应；同镜不连续堆多个 crack，源剧情没有可完全不用。

**A6.6 表演通道适配（必写）。** 脸可见→眼神 + 面部极小变化；仅手可见→握力 + 动作节拍 + 触碰；背影可见→重心 + 肩颈 + 呼吸；脚部可见→步态 + 重量转移；全身远景→姿态 + 空间占据。**只写本镜实际能看见的通道。**

**A6.7 反应与台词的相对时机。** 反应可在对方台词结束前开始，但必须有明确触发词/动作；不要机械规定所有反应等都说完或都提前。

**A6.8 克制型爆发。** 强情绪可对 **AI 自己添加的表演装饰**做减法（少一个皱眉、少一次叹气）；不得删除、替换或延后用户原剧情的动作/对白/反应。

**A6.9 微表情事件数。** 一镜（3–8s）通常 0–2 个源剧情已有的微反应；**0 个完全允许**，不得为凑数新增；只见手/背影就不写面部微表情。

## A12. 交付前抛光（单次执行）

发现普通表达问题直接修；结构级硬冲突按 A12.20 处理，不递归返回。

**A12.1 首帧锁定。** 按 `drama_craft` §2 的八段式（CHARACTER / ACTION / 环境 / 摄影 / 光线 / 氛围 / 声音 / 禁止）写首帧。适用项：本镜是否有人物（无人明确写「空镜，无人物」）、站/坐/蹲/躺、画面左右、相对距离、身体朝向、视线初始落点（有明确关注对象照写，没有只用不承载新信息的中性落点，不推断兴趣/敌意/暧昧）、手里拿什么、关键道具摆在哪、摄影机距离与高度、前中后景。不适用项不要硬编。**首帧主体必须是角色，不能是道具。**

**A12.2 出镜锁定按镜。** 本镜不该出现的角色显式写：完全不出镜；不出现脸/身体/肩膀/手/倒影/影子/焦外人形（按需选）；仅画外同期对白要明确「只有声音」。主观镜头、局部镜头、肩后镜头、单人镜头尤其要防模型自动补出另一个角色。

**A12.3 光学写可见结果。** ❌「85mm f/1.4」→ ✅「短焦肖像感视角，面部透视自然，背景轻度虚化」。镜头型号可以辅助，重点是最终画面结果。

**A12.4 摄影机矛盾检查。** 每镜只保留一个主要运动逻辑。❌「完全固定，同时缓慢横移」→ ✅「摄影机固定，仅做一次极慢移焦」。

**A12.5 回避摄影（仅克制/含蓄风格）。** 可优先：手部特写/杯子/红绳/地板边缘、肩后/柱子遮挡/虚焦前景、双人中景/固定远景。不套用到动作片、强喜剧、产品实验等其他风格。

**A12.6 表演写行为。** 见 A6.1；优先把**源剧情已经存在的反应**写成可见动作，不得作为 AI 自行添加的新表演事件。

**A12.7 微表情密度。** 每角色每镜通常 0–2 个明确微表情事件；镜头看不到脸时不写脸部反应。

**A12.8 眼神目标具体化。** 只有原文写明角色在看某人/物/方向才写具体；原文没有关注对象时不得自选一个有剧情含义的目标。「眼睛先动 → 头部后跟」只用于表现已有看向动作，不新增一次看向。

**A12.9 双人动作避免机械同步。** 源剧情本身含两个可并行、未锁精确同步的已有动作时，可轻微错开节奏；**不得新增动作、延后关键事件或改变原本明确的同时发生关系**。

**A12.10 动作因果链。** 把已有源节拍组织成清楚因果链；原文有多个动作就全部保留，只在镜头承载上分配，不为「每镜一个核心动作」删事件；删除 AI 自加的装饰动作。

**A12.11 道具连续性。** 见 `40-staging-continuity.md` §A8.3。交付前再扫：持有人/使用手/绝对位置/可见或遮挡/数量/朝向/开合/液面或内容物/损耗/污渍湿度/末态。禁止无因恢复或重置：喝过的杯子突然满、擦开的污渍复原、打开的门无动作闭合、破损道具自动完好、已消耗物件恢复数量。

**A12.12 物理真实性。** 液体惯性、衣料褶皱、手与道具接触、物体重量、桌面震动、碰撞反馈、玻璃折射/反射。

**A12.13 光线一致性。** 同一连续场景保持主光方向、色温与曝光逻辑；换场/时间跳跃按 `40-staging-continuity.md` §A5.5 重新建立。禁止仅因剧情重要突然加轮廓光、增强眼神光或改曝光（用户风格明确要求除外）。

**A12.14 声音。** 默认只保留真实同期对白与环境/动作声；BGM、配乐、情绪音效以用户要求为准，未要求则不加，**默认无背景音乐**。

**A12.15 对白原文与时长。** 原文照抄，不改词/不换句式/不加语气词/不重复/不即兴。**不得靠加快语速**解决塞不下（这类问题应在 `30-output-check.md` 的 A11 处理）；抛光只微调不改变结构的停顿措辞。

**A12.16 正向锁优先。** 先写可执行状态（「角色 A 本镜始终位于画面左侧」「杯子由角色 A 右手持有」「角色 B 本镜完全画外」），再补必要禁止项。

**A12.17 文字与引用。** 文字锁、`@名字` 引用即锁定、引用后不重描外貌，写法见 `drama_craft` §3.1/§3.2。抛光阶段只检查：后期字幕/叠字没交给生成模型；实体资产文字没要求模型重绘；引用后没有重复描述外貌。

**A12.18 统一限制按需添加。** 按需选：不增加人物/道具/对白/剧情动作；不无故越轴、不无过程交换人物位置；不做 MV 式快剪；不做风格依据外的广告式补光/磨皮；不夸张景深；不使用不自然慢动作。**不要机械粘贴与当前镜头无关的限制。**

**A12.19 最终连续性与穿帮审计（交付前强制 · 单向 · 不返回）。**

1. 对每镜建起态/末态快照：人物世界位置、姿态、朝向、出镜状态、手部占用；关键道具持有人/位置/数量/状态；门窗家具、污渍、光源等持续状态。
2. 只比较 `40-staging-continuity.md` §A8 判定为「连续关联 / 局部状态关联」的镜对；无连续关系的相邻镜不强行比位置，只检查本镜自身。
3. **人物穿帮**：无来源瞬移、无来源换边、无过程站↔坐、同一人物同一世界位置重复成两人、画内/画外与机位描述矛盾。
4. **道具穿帮**：无来源消失、复制、换手、回手、数量变化、开合重置、液面/污渍/破损恢复；尤其「上一秒还拿着，下一秒同一只手清楚可见却空了」。
5. **空间穿帮**：固定家具移位、门窗状态跳变、穿墙/穿桌、物件穿手、角色与桌椅尺度突变、反射/镜像里多出不存在的人物或道具。
6. **崩坏风险**：高风险镜是否已按 `30-output-check.md` 的 A11.4 降低运镜/遮挡/景深/并发接触/参考冲突，并加必要定向 Avoid。
7. **保真复核**：所有修正只能改摄影表达、锁定信息、遮挡/可见性描述、镜头承载；不得新增「放下笔」「重新拿笔」「走回原位」等桥接动作掩盖穿帮。

AI 草稿自身矛盾 → 本次直接修成与已确认状态一致；源剧情自身矛盾 → 保留原文并在总览标「源文本冲突」。
**这是提示词侧的穿帮风险审计，不等于真实视频无穿帮。** 多手多指、肢体融合、人物变脸、道具闪现/消失、穿模、镜像错误必须在媒体实际可读时另做结果验收。

**A12.20 优化边界与终止条件。**

不许改：用户原文台词；任何源剧情 `E##` 的动作、反应、事件数量、执行者、承受者、道具、信息与因果；用户原文的模糊身份层级（「父母/家长/成人」不具体化）；剧情核心意图；已确认的节拍顺序；全片实际镜数/各镜时长；全局镜号与批次；关键资产身份；已确认的世界坐标逻辑。

只允许：写得更具体可执行、补齐首帧与出镜锁、减少过度表演、补物理/光线/声音/连续性表述、清理互相矛盾的措辞。

**终止规则：完成一次后只做最终勾选，不返回 `30-output-check.md`，不触发第二次抛光。**

最终勾选：`E##` 全部出现且顺序/执行者/对象/台词未变；无无源新增剧情；无补前史、补来源、擅自具体化；首帧适用项齐且主体是角色；每镜出镜状态与资产规划一致；无摄影机矛盾；表演可见不过载；眼神目标具体；道具/物理/光线连续；相邻镜已判定关联且连续段一致、无关联段未被错误强锁；关键道具无无源消失/复制/换手/回手/数量变化/状态重置，裁切遮挡未误判为状态变化；已完成空间/门窗/家具/反射/镜像/穿模审计；高风险镜已降复杂度；对白原文无改动；无 AI 新增字幕叠字；实体文字按参考资产处理；无结构回滚与循环。

勾完即输出最终版。
