# 文字分镜技能

## 输出格式

每个镜头一行：

```
镜头号 | 画面描述 | 台词/旁白 | 时长(秒)
```

## 硬性要求

1. 画面描述必须具体到"能拍"：写清景别、主体动作、机位运动
2. 时长总和必须等于用户给定的总时长，误差为 0
3. 台词要口语，不要书面语
4. 不确定的信息写"待确认"，不要编
