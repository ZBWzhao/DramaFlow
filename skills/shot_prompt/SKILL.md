# 片段提示词技能

## 一、一条铁律：资产描述只有一个出处

**不要在提示词正文里自己写参考声明。**

资产长什么样，只写在**资产节点**里（`name` + `consistency_tags`）。
提示词正文里只用占位符 `{{ref N}}` —— 导出时系统会把它们展开成
`【参考1】= 角色·陈默（黑色短发、左眉尾旧疤、湿透的黄色外卖服）` 并放在最前面。

为什么：手写声明 = 同一份设定存两处 → 一定会漂移（实测已经出现过：
正文自称 3 个参考，而画布上只连了 2 条边，导出时被校验抓出来）。

## 二、能用的编号从哪来

`get_canvas` 的返回里，每个提示词节点会显示：

```
可用引用：{{ref 1}}=角色·陈默, {{ref 2}}=场景·深夜便利店
```

**只能用这些编号**。如果你想要的资产不在列表里 → 说明它没连到这个片段 →
用 `connect_nodes` 把它连上（从资产的 `ref` 端口连到提示词的 `ref` 端口），再重新读一次。

## 三、正文怎么写（三段式）

```
镜1｜0-4s｜中景｜{{ref 1}} 推开门走进 {{ref 2}}，脚步在门口停住；固定机位；门铃声与雨声
镜2｜4-8s｜近景｜{{ref 1}} 与店内女子对视，扫码枪停在半空；镜头缓慢推近；环境音渐弱
镜3｜8-12s｜特写｜{{ref 1}} 的左手与{{ref 2}} 的收银台边缘；手指微微发抖；纸袋落地声

风格：写实、冷白荧光、轻微手持晃动。不要出现文字水印、不要多人同框特写。
```

- **一行一个镜头**，格式：`镜N｜起止秒｜景别｜画面（用 {{ref N}} 指代角色/场景）｜运镜｜声音`
- 时间范围要连续、不重叠，总和 = 该片段时长
- 结尾一行写风格与禁止项（negative）

## 四、片段与节点的对应

- 一个片段 = 一个 `prompt` 节点 = 一份提示词（不要拆成两个）
- 写正文用 `set_text`，不要塞进节点的 data
- 写完把节点 `status` 置为 `ready`（用 `update_node`）
- 片段信息写进节点 data：`{"segment_no": 1, "duration": "0-16s"}`

## 五、写完要自查

1. `get_canvas` 再看一遍：有没有"未展开的编号"告警、体检问题
2. 每个 `{{ref N}}` 都要能在"可用引用"里找到
3. 时长加总是否等于要求的总时长

## 六、不要做的事

- ❌ 不要自己写 `【参考1】= …` 这样的声明（系统会生成）
- ❌ 不要用没连线到本片段的资产编号
- ❌ 不要在正文里重复描述角色长相（那是资产节点的事）
- ❌ 不要输出与分镜矛盾的镜头顺序
