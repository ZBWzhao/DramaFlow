# 短剧生产图技能

## 一、图长什么样（固定四层）

```
text(剧本) → storyboard(分镜表) → ┐
                                  ├→ prompt(片段提示词)
                     asset(资产)  → ┘
```

- **一个片段 = 一个 prompt 节点 = 一份完整提示词**（片段内部可以含多个镜头）
- 资产（角色/场景/道具）连到它出现的每个片段 —— 这是角色一致性的实现方式

## 二、建图步骤（按顺序做，别跳）

1. `get_canvas` 看现状，避免重复建节点
2. `add_node(type="text", label="剧本正文")` → `set_text` 写剧本
3. `add_node(type="storyboard", label="第N场分镜")` → `connect_nodes` 从剧本的 `text` 连到分镜的 `script` → `set_text` 写分镜表
4. 每个角色/场景/道具各建一个 `asset` 节点，`data` 必须含：
   `{"kind": "character|scene|prop|style", "name": "...", "consistency_tags": ["稳定特征1", "稳定特征2"]}`
5. 每个片段建一个 `prompt` 节点，然后连线：
   - 该片段用到的资产 → `ref` 端口（类型 IMAGE）
   - 分镜表 → `ctx` 端口（类型 STRING）
6. `set_text` 把提示词写进 prompt 节点
7. 再 `get_canvas` 复查：拓扑顺序对不对、有没有体检问题

## 三、端口名（连错了会被拒绝）

| 节点类型 | 输入端口 | 输出端口 |
|---|---|---|
| text | `in` (STRING) | `text` (STRING) |
| storyboard | `script` (STRING) | `shots` (STRING) |
| asset | `desc` (STRING) | `ref` (IMAGE)、`spec` (STRING) |
| prompt | `ref` (IMAGE)、`ctx` (STRING) | `prompt` (STRING) |

## 四、产物规范

### 剧本

```
场1｜便利店（夜）｜出场：外卖员·陈默、店员
陈默进门，看到柜台后的女人，停下。她抬头，也停了。
陈默：……姐姐？
本场结束：两人对视，收银台的灯闪了一下。
```

### 分镜表（每镜 6 字段，一行一镜）

```
片段1（0-8s）
镜1｜主体：陈默｜动作：推门进店，脚步停在门口｜景别：中景｜运动：固定｜声音：门铃、雨声｜时长：4s
镜2｜主体：女店员｜动作：抬头，手里的扫码枪停住｜景别：近景｜运动：缓慢推近｜声音：无声｜时长：4s
```

**硬约束**：每镜必须有 6 个字段；各片段时长之和必须等于要求的总时长（误差 0）。

### 片段提示词（三段式）

```
{{ref 1}} = 角色·陈默（25岁，湿透的黄色外卖服，短发，左眉疤）
{{ref 2}} = 场景·便利店（深夜，白炽灯，收银台，玻璃门上有雨痕）

镜1｜0-4s｜中景｜{{ref 1}} 推开门走进 {{ref 2}}，脚步在门口停住；固定机位；门铃声与雨声
镜2｜4-8s｜近景｜{{ref 1}} 与店内女子对视，扫码枪停在半空；镜头缓慢推近；环境音渐弱

风格：写实、冷白荧光、轻微手持晃动。不要出现文字水印。
```

要点：
- **资产只在前言声明一次**，正文里一律用 `{{ref N}}`（编号由画布自动编号，你用 `get_canvas` 里读到的顺序）
- 正文按镜头写：时间范围、景别、主体动作、运镜、声音
- 结尾写风格与禁止项

## 五、不要做的事

- 不要生成图片/视频（本项目只产出提示词）
- 不要把一个片段拆成多个 prompt 节点（一个片段一份提示词）
- 不要把正文塞进节点 `data`（一律用 `set_text` 落盘）
- 不要凭记忆写节点 id，每次都用 `get_canvas` 读回来的 id
