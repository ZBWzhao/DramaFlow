# 短剧提示词工艺（图 / 首帧 / 视频 三层）

> 本技能改编自开源项目 [AI-short-play-video-creation](https://github.com/ADC1920/AI-short-play-video-creation)（MIT），
> 结合本系统（Toonflow 制片台 + Seedance 系列）的实测经验重写。规则来自千百次失败样本，不是审美偏好——
> 每条后面都写清「不这么做会怎样」。

## 零、一切错误的总根源：三层混着写

同一套提示词不能同时满足三个层。这是本项目过去全部翻车的共同原因。

| 层 | 产物 | 目标 | 关键词 | 用错会怎样 |
|---|---|---|---|---|
| 素材层 | 角色/场景/道具设定图 | **信息完整、可辨认** | 平光、纯色底、单角度、无戏剧光 | 把「身份证」当首帧用 → 视频只会让设定图轻微抖动 |
| 首帧层 | 每个镜头的第 0 秒画面 | **构图与调度正确** | 戏剧光、三层景深、站位与视线 | 首帧构图错 → 视频全错，怎么重跑都没用 |
| 视频层 | 一段连续镜头 | **动作连贯、身份不漂** | 只写动作/景别/运镜/声音 | 重描外貌 → 引用失效，换脸 |

**改法**：素材图只写「长什么样」；首帧图写「这一格画面长什么样」；视频提示词只写「这一格之后发生了什么」。

## 一、素材层：身份证工艺

### 1.1 锚点法（角色一致性唯一可靠做法）

1. 先出一张**正面全身锚点图**：平光、纯灰底、正面、中性表情、双手自然下垂、全身入画。
2. 其余视角/表情/状态图**只参考锚点图衍生**，不要另起提示词重写外貌。
3. 锚点定稿后冻结，全剧不换。改锚点 = 全剧角色变人。

### 1.2 一图一人，不要三视图并排

**这是最贵的坑**。正/侧/背并排的设定图，图片模型画得没问题，但视频模型会把并排的三个人读成
**三个不同的人**，于是镜里多出重复角色、或者人物在画面里「分裂」。

- 一个角色 = 多张**单角度单图**：正面全身 / 正脸特写 / 侧面 / 背面，**分开存**。
- 视频请求里同框参考图 **≤ 2 张**（1 个主角 ref + 场景）；3 个以上主角同框，一致性会掉到 50% 以下。
- 同框多角色时：**1 个主 ref + 其余用文字/剪影描述**，不要让模型同时读三张脸。

### 1.3 资产节点字段、consistency_tags 与素材提示词形状

资产节点只交**结构化字段**，提示词正文由服务端按字段渲染（写入 `data.prompt`，并置
`data.rendered_by = "server"`；人工改过的置 `human`，此时不再覆盖）。

```jsonc
{
  "kind": "character",              // character | scene | prop | style
  "name": "灰蓝士兵",
  "anchors": ["左虎口一道旧疤", "钢盔左侧一道凹陷划痕"],
  "forbidden": ["不出现现代军装", "不出现三视图并排"],
  "consistency_tags": ["深灰蓝土布作训服", "同色污泥钢盔", "右侧脸颊旧擦伤"],
  "spec": "正面全身，平视，中性表情，双手自然下垂，全身入画"
}
```

**consistency_tags 的写法**（3–6 条，多了会互相抢注意力）：

- 每条都要**能被画出来**：✓ `低马尾`、`右腕细银链`、`湿透的黄色制服`；
  ✗ `温柔`、`沧桑`、`有故事感`、`普通中年男人`
- **不要写会变的**（情绪、动作、位置）——那些属于镜头，不属于资产
- 一旦定稿就**冻结**：改了，整部戏的前后一致性就断了
- 标签串是**给校验器比对的数据**，不进提示词正文；正文只写连续描述（见下）

**素材提示词的固定形状**（服务端渲染模板）：

```
<角色名>，<年龄><性别>，<体型>，<发型>，<服装>（含材质与脏污程度），<2-3 条可画出的识别特征>。
正面全身，平视，中性表情，双手自然下垂，全身入画，脚下留一点空间。
棚拍柔光，无阴影，纯中性灰背景，无投影。写实电影质感，皮肤纹理清晰。
不出现文字、水印、边框、多格排版、多余人物。
```

三类资产的差异：

- **场景**：`<空间名>，<关键结构 3-4 个，含相对位置>，<光源>，<色调>。广角，平视，无人。`
  **场景图不要出现人**——一旦有人，后面每个用这张图做参考的镜头都会被塞进这个人。
  `consistency_tags` 写空间要素 + 光源 + 色调（`城郊便利店`、`惨白日光灯`、`收银台正对门口`）。
- **道具**：只给剧情关键道具建资产；要**给物品一个姿态**（`平放在粗糙水泥面上`、`俯拍平视、微距质感`），
  正视角白底单品在成片里会像贴纸。特征要细到可辨认：`细银链`、`链身有划痕`、`挂着小圆牌`。
- **风格**（`kind: "style"`）：锁全片统一的美术风格，只写「看起来像什么片子」，不写角色或场景内容。
- 场景在戏里发生变化（灯坏了、天亮了）就**建两个场景资产**，不要改同一个；不出现的角色不建资产。

### 1.4 分镜信息块：角色 6 类 / 场景 4 类 / 道具 4 类

资产节点存「身份证」，分镜里存「本镜用到的部分」。**不要复制整套角色档案**，只留本镜需要的锚点。

**角色条目必含 6 类**：① 身份 + 外观锚点（只引用已给定信息，缺则标「设计提案」）② 本镜出镜状态 ③ 世界坐标 + 画面坐标 ④ 本镜特殊状态（脏污/伤口/湿度/持物）⑤ 重点表演 3–5 条可见要求 ⑥ 同期台词原文。

**出镜状态词表**（按本镜实际可见范围选，同一镜两种以上状态要分别写）：实际出镜并说话 / 实际出镜不说话 / 仅面部局部 / 仅手部 / 仅肩后 / 仅背影 / 仅脚部 / 完全画外仅同期对白 / 完全画外无声音。

**场景条目必含 4 类**：① 场景锚点 ② 摄影机位置 + 朝向 + 高度 ③ 前景/中景/后景 ④ 人物与地标的相对关系、轴线。

**道具条目必含 4 类**：① 镜首绝对位置 / 使用者 / 状态 ② 本镜时间轴动作（谁、何时、怎么动）③ 镜末状态 ④ 禁止项；有包装文字时写「保持参考资产外观，不新增、不改写、不重绘」。

**禁止**：写未出现的资产；把资产标识写成重复一遍完整剧情；用「本镜实际出镜并说话（但镜头 1 又画外）」这种自相矛盾的总括写法；要求模型凭空生成精确包装文字来替代参考资产。

## 二、首帧层：8 段式

出每个镜头的第 0 秒画面时，按这 8 段写，缺哪段就补哪段：

```
CHARACTER: <画面里有谁，各自在画面什么位置、什么朝向、什么姿态，谁看谁>
BACKGROUND: <背景结构，前/中/后景分别是什么>
ACTION: <定格在动作的哪一瞬间，可见的身体状态（手在哪、重心在哪、表情肌在哪）>
SCENE: <时间、天气、环境介质（烟/尘/雨/火光）>
CAMERA: <景别代码 + 机位高度 + 角度 + 构图关系（谁在左谁在右、是否过肩/双人同框）>
LIGHT: <主光方向与色温、轮廓光、明暗比>
TEXT: <画面内应出现的文字；没有就写「无任何文字」>
STYLE: <写实电影质感 / 动画风格，胶片颗粒，色调>
```

三条硬要求：

- **视线必须有目标**：谁在看谁、何时移开。没有视线目标的双人镜，模型会让人物各自看镜头。
- **景别必须显式写**：`特写/近景/中景/全景/大远景` 里挑一个，不要只写「镜头拉近」。
- **写可见末态**：「他很愤怒」不算，「下颌绷紧、鼻孔扩张、手背青筋凸起」才算。

> 实测：只用镜头一行摘要（「刀锋离皮肤一寸」）出首帧，模型会画成「一个人拿铲子怼自己脸」。
> 首帧提示词必须给足**站位与朝向**，这是构图崩坏的第一原因。

**首帧适用项**（逐项过一遍，本镜不需要的就不写，不硬编）：

| 项 | 怎么写 |
|---|---|
| 有人 / 无人 | 有角色就写是谁；无人的空镜要明确「空镜无人物」 |
| 姿态 | 站 / 坐 / 蹲 / 躺，不写「自然地」 |
| 画面左右 | 「画面左三分之一」这种绝对位置，不写「旁边」 |
| 相对距离 | 「半步距离」「隔一张桌」，不写「不远处」 |
| 身体朝向 | 「身体朝画面右，略微侧对镜头」 |
| 视线初始落点 | 看向谁 / 看向哪件道具 / 看向画外 |
| 手里拿什么 | 有就写，没有写「双手空闲」 |
| 关键道具位置 | 在谁手里、在桌上哪个位置 |
| 机位 | 距离（远/中/近/特）、高度（平视/俯/仰） |
| 前中后景 | 至少交代前景有什么、后景有什么 |

## 三、视频层：只写动作

一段视频 = 一个连续镜头。**不要在一条提示词里写多个镜头**——视频模型不会切镜，它只会乱猜，
实测结果是「满屏糊泥的宏观特写」「场景图轻微推拉」「两个对手并排蹲着」。

### 3.1 引用即锁定（第二条命）

**@ 引用素材之后，禁止再用文字重描该主体的外貌**（脸型/发型/服装/年龄）。

ref 与文字是**权重冲突**，不是叠加。重描会让 ref 失效 → 换脸、变形。
外貌在素材阶段定稿；镜头提示词只写：动作 / 景别 / 运镜 / 光线 / 声音。

**引用语法（全系统统一）**：用 `@名字` 引用资产；代码里 `_replace_ref` 兼容旧写法 `{{ref N}}`，但那只用于读历史画布，新内容一律写 `@名字`。

- **用户已有标签库** → 原样引用其标签（如 `@HERO1V2`、`#老宅客厅`），不改名、不缩写、不重新编号；**禁止用上一镜的尾帧画面当站位参考**——站位只能靠绝对坐标的文字重建。
- **用户没有标签库** → 只用中文名，清单写 `角色｜林直人`，正文直接写「林直人」，资产名不加 `@`；同类多资产用中文区分（「直人杯 / 佐藤杯」），不要造编号。
- 两种情况都不要在引用后再描述一遍脸型/发型/服装/年龄。

### 3.2 视频提示词的固定形状

```
@角色A @角色B @场景 @道具
<景别代码>，<机位/运镜>。
动作：<一件连续动作，写明起点与终点（可见末态）>。
光线：<方向、色温、变化>。
声音：仅环境音：<……>。
单镜头连续拍摄，不切镜、不换机位、不出现新角色。身份、服装、泥污与参考素材完全一致。
不出现任何文字、字幕、水印、BGM。
```

- **景别代码**：ECU 极端特写 / CU 特写 / MCU 近景 / MS 中景 / LS 全景 / ELS 大远景。
- **人物动作与摄影机运动分开写**，不要混在一句里。
- **声音符号**：（音乐）<音效>{台词}【字幕】。本系统默认静音出片，声音只作氛围说明。
- **否定失效**：写「不要 X」时，X 的词根一旦留在提示词里就会被当画面词渲染。
  正确做法是**让词根零出现**：把「不出现血腥」改写成「画面干净、冷色调」；把「不要多人」改写成「画面中只有一个角色」。

### 3.3 时长与节奏

- 单镜 **4–6 秒**。超了模型会自己填时间，填法是「无意义动作」。
- 一段里状态变化 **≤ 4 个**，超了整段会被跳过。
- 同景别不要连续超过 2 镜；每 25–30 秒安排一个情绪峰值。
- 台词折算：中文约 4–5 字/秒，镜头时长 ≥ 台词字数 ÷ 5。
- 本系统当前按**一镜一段**出片；Seedance 2.5 的多时间块写法未启用，备查见 `docs/seedance-25-timeline.md`。

### 3.4 文字锁

文字是模型最容易「自己加戏」的地方，默认全部关掉，只在确有必要时开。

- **后期型文字**（字幕、标题、说明卡、UI 叠字、水印）：默认禁止。提示词里明确写成「无字幕、无额外屏幕文字、无后期文字叠加」，不要只写「不要字幕」——模型会把否定词读成肯定。
- **实体文字 / 包装文字**（招牌、书封、商品包装、票据）：有参考资产时写「严格保持参考资产外观，不新增、不改写、不重绘」；**不得要求模型生成清晰准确的新文字**，它做不到，只会糊成乱码。
- **没有参考资产时**：不要求文字清晰可读，画面里出现模糊文字是正常的，不要在提示词里索要内容。
- **用户明确要求读出某个文字时**：逐字锁定原文（加引号、给全称），并明确提示这是高风险项，可能需要后期替换或单独补拍。

## 四、多人戏：先排后写

同框 2 人以上，**写提示词之前先做四件事**，否则必然出现「两个对手并排蹲着」：

1. **俯视站位**：以固定物件为坐标写清楚——谁在门边、谁在桌子另一侧、谁挡着谁、通道在哪。
2. **走位链**：谁动 → 谁看到 → 谁反应 → 谁移动 → 新站位。配角不许凭空出现或消失。
3. **视线目标**：谁看谁，何时转向，何时移开。只让在场且知情的人反应，避免全员同步震惊。
4. **反打检查**：左右关系、视线高度、光源方向必须一致；无意越轴不允许。

写进首帧提示词的 CHARACTER/CAMERA 两段里。

## 五、段与段之间

模型每段**零记忆**。相邻两段不设计衔接，必跳。

- 第一种衔接：**首帧接力**——上一段的尾帧截图作为下一段的首帧输入。同一序列内只用一种方式，不要混用。
- 第二种衔接：**末态双保险**——上一段提示词末尾写死末态，下一段提示词开头重述同一末态。
- 换机位硬切、空镜过渡是另外两种合法做法；不要在同一序列里混搭。

## 六、自检清单（每版提示词发出去前过一遍）

- [ ] 这一条只写了一个人的一段动作吗？有没有偷偷写第二个镜头？
- [ ] 有 @ 引用吗？引用之后还重描外貌了吗？
- [ ] 景别写了吗？是五个代码之一吗？
- [ ] 每个人的视线都有目标吗？
- [ ] 末尾的末态是**可见**的吗（身体/表情/物体位置），还是情绪形容词？
- [ ] 「不要 X」里的 X 词根，别的句子里还留着吗？
- [ ] 单镜时长 ≤ 6 秒、状态变化 ≤ 4 个吗？
- [ ] 首帧提示词写了站位与朝向吗，还是只有一句动作摘要？

## 七、排障速查

| 症状 | 首修 |
|---|---|
| 换脸 / 人脸漂移 | 检查是否重描了外貌（引用即锁定）；加一张正脸特写 ref；同框 ref 降到 ≤2 |
| 同一角色出现两个 | 三视图并排被读成多人 → 改单角度单图；每个角色在各处都用同一个 @名字 |
| 冒出字幕/水印 | 提示词加「画面中不出现任何文字与字幕、不生成任何水印与标志」 |
| 构图崩坏（人不在该在的位置） | 首帧提示词缺站位/朝向；补 8 段式里的 CHARACTER + CAMERA |
| 动作漂 / 肢体崩 | 把复合动作拆成单个动作重抽；单镜压到 4 秒内 |
| 场景只是轻微推拉 | 用错模式：这是把素材图当参考图喂视频了。必须走「首帧」模式 |
| 两个对手看起来像战友 | 多人戏没预排。补俯视站位 + 视线目标，重出首帧 |
| 写明的运镜被忽略 | 把该运镜写成这一镜的**主要意图**，而不是并列描述之一 |
| 提示词写了「不要 X」还是出现 X | 否定失效：让词根零出现，或改主体优先句式 |
| 长提示词批量失败 | 提示词与并发不可兼得：单跑，或并发 ≤4 并带退避 |

## 八、成本纪律

- **先图后视频**：首帧图成本约是视频段的 1/15–1/20。构图问题永远在静态图上解决，不要用视频试错。
- 关键镜出 2–4 张首帧候选选优，过渡镜 1 张即可。
- 批量生成前先出 1–2 镜样片确认风格，再批量。
- 单集重生控制在 ~10%；超了就停下检查素材与提示词的系统性问题，别硬刷。
