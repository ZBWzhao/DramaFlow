# 资产设定规范

## 一、为什么要做资产

生成模型**不知道你的角色是谁**。每个片段单独生成时，角色会长得不一样。
解决办法不是"每次把描述再写一遍"，而是：

1. 每个资产（角色/场景/道具）**只设定一次**
2. 设定写成 `consistency_tags`（能被拼进每条提示词的稳定特征）
3. 每个片段用 `{{ref N}}` 引用它 —— 编号指向同一份设定和同一张参考图

## 二、角色参考图（关键做法）

同一个角色在不同镜头里要认得出，参考图比文字更有效。给每个主要角色准备：

| 图 | 内容 | 用途 |
|---|---|---|
| 正面全身（锚点） | 平光、纯灰底、正面、中性表情、全身入画 | 锁体型与服装，其余图都从它衍生 |
| 正脸特写 | 正脸、无遮挡 | 锁五官 |
| 状态图（可选） | 淋湿 / 受伤 / 换装 | 同一角色的不同状态 |

⚠️ **一个角色 = 多张单角度单图，不要做「正/侧/背并排」的三视图。**
图片模型画三视图没问题，但**视频模型会把并排的三个视图读成三个不同的人**，
成片里就会出现重复角色、或者人物在画面里分裂。要侧面就单独出一张侧面图。

写进节点 `data.looks`（每项一张单图）：

```json
{
  "kind": "character",
  "name": "陈默",
  "consistency_tags": ["25岁男性", "湿透的黄色外卖制服", "黑色短发", "左眉尾一道旧疤"],
  "looks": [
    {"name": "正面全身", "prompt": "25岁男性全身正面，湿透的黄色外卖制服，黑色短发，左眉尾一道旧疤，平光，纯灰背景"},
    {"name": "正脸特写", "prompt": "同上人物面部特写，正面，中性表情，纯灰背景"}
  ]
}
```

## 三、consistency_tags 的写法

- 数量 **3–6 个**，多了会互相抢注意力
- 每条都要**能被画出来**：
  - ✓ `低马尾`、`右腕细银链`、`惨白日光灯`、`玻璃门挂雨痕`、`湿透的黄色制服`
  - ✗ `温柔`、`沧桑`、`有故事感`、`普通中年男人`
- **不要写会变的**（情绪、动作、位置）—— 那些属于镜头，不属于资产
- 一旦确定就冻结：改了，整部戏的前后一致性就断了

## 四、场景

- 场景资产解决"空间连续性"：同一个便利店在不同片段里门、收银台、灯的位置要一致
- `consistency_tags` 写清：**空间要素 + 光源 + 色调**
  例：`城郊便利店`、`惨白日光灯`、`收银台正对门口`、`冷柜蓝光`
- 若场景在戏里发生变化（灯坏了、天亮了），**建两个场景资产**，不要改同一个

## 五、道具

- 只给**剧情关键道具**建资产（推动情节的：手链、信、钥匙），普通道具不建
- 特征要细到可辨认：`细银链`、`链身有划痕`、`挂着小圆牌`、`刻着模糊的"湘"字`

## 六、风格

- `kind: "style"` 的资产用来锁**全片统一的美术风格**（配色、笔触、质感）
- 风格资产**不要**写角色或场景的具体内容 —— 它只管"看起来像什么片子"
- 例：`写实短剧质感`、`冷白荧光`、`轻微手持晃动`

## 七、不要做的事

- ❌ 不要在提示词里重复角色长相（违反"单一出处"）
- ❌ 不要用感觉词当特征
- ❌ 不要给不出现的角色建资产（资产也要有取舍）
